# .forkhub

Patch intents managed by [forkhub](https://github.com/ImBIOS/forkhub) (`fh`) — patches are intent, not diffs.

Public intent repository. Import any patch:

```bash
fh import https://github.com/ImBIOS/.forkhub/blob/main/repos/github.com/<owner>/<repo>/patches/<patch-id>/INTENT.md
```

Browse with `fh search --author ImBIOS`.
